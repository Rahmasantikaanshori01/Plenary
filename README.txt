PLENARY FRONTEND
================

Isi:
index.html
style.css
script.js
buyer-login.html
seller-login.html
admin-login.html
login.css
login.js

CARA MENJALANKAN
1. Extract ZIP.
2. Buka folder hasil extract sebagai folder di VS Code.
3. Pastikan file CSS ada di folder yang sama dengan HTML.
4. Jalankan index.html memakai Live Server.
5. Buka buyer-login.html / seller-login.html / admin-login.html untuk login.

PENTING:
Jika tampilan tiba-tiba sangat kecil/sempit seperti screenshot sebelumnya:
- Tekan CTRL + 0 di Chrome/Edge untuk mengembalikan zoom browser ke 100%.
- Refresh dengan CTRL + F5.
- Jangan membuka file HTML dari folder yang hanya berisi HTML tanpa file CSS/JS.

Animasi teks:
Setiap karakter dibuat menjadi elemen sendiri. Cursor yang mendekati karakter akan membuat karakter naik/membesar, sedangkan karakter yang tepat dilewati cursor berubah warna secara individual.
